# Определение дня недели по порядковому номеру

## Поддерживаются два типа нумерации дней:
1. Отсчёт начинается с Понедельника (1 — Понедельник ... 7 — Воскресенье).
2. Отсчёт начинается с Воскресенья (1 — Воскресенье 2 — Понедельник ... 7 — Суббота).

Программа проверяет корректность ввода как для типа нумерации, так и для диапазона дней (1–7).

## Логическая составляющая

Для реализации разветвленной логики используется вложенная конструкция выбора `switch-case`:

`switch(type)` разделяет логику на две ветки в зависимости от выбранного календаря.
`switch(day)` сопоставляют введённую цифру с конкретным днём недели для выбранного типа нумерации.
`default` обрабатывает ошибочный ввод пользователя.
